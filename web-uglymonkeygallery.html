monkeygallery.net

2023 • HTML, CSS

Challenged to create the ugliest, most dysfunctional site. This was the result!

Overview

monkeygallery.net was born from a challenge to create the ugliest, most dysfunctional HTML/CSS website possible. Its chaotic visuals, clashing elements , and deliberately confusing interface set the tone immediately. The site includes a fake directory, numerous dead-end pages, and an intentionally frustrating navigation flow—all designed to delay the user from reaching the actual “monkey gallery.” Once they finally discover it, the images behave counterintuitively, shrinking on hover instead of enlarging. The result is something truly… unique—and nearly unusable. Ironically, crafting a site this bad requires a deep understanding of how to make a good one; producing something wholly dysfunctional takes a surprising amount of functional design and programming awareness.
