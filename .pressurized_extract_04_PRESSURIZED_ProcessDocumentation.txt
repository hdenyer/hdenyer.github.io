Origins: Capstone I PRESSURIZED began as a project called Control Deck during Capstone I. The
initial

prototype

established

the

core

concept:

a

Unity

video

game

played

not

with

a

conventional

controller,

but

with

a

handcrafted

panel

of

physical

inputs.

The

prototype

featured

a

timer

bar,

basic

command

prompts

displayed

through

hand-drawn

images

of

inputs,

and

a

simple

scrolling

underwater

scene.

While

early

user

testing

conﬁrmed

the

concept

was

intriguing

and

that

players

always

wanted

to

try

again,

it

also

revealed

critical

weaknesses:

command

prompts

were

initially

too

vague

to

parse

quickly,

and

after

extended

play,

the

game

became

repetitive

and

too

easy.

Users

often

ignored

the

submarine

visuals

entirely,

undermining

the

visual

design.

Capstone II: Planning and Scope Deﬁnition At the start of Capstone II, the project entered an analysis phase. Four
milestones

were

deﬁned

for

the

semester:
1. Increase Interactive Game Elements: Add a specimen collection mechanic,
boss

battles,

and

dynamic

creature

spawning

to

deepen

gameplay.
2. Cater to the Arcade Format: Implement a complete game loop with a start
screen,

end-game

scoring

screen,

and

combo-based

dynamic

scoring.
3. Reformat and Expand the Controller: Replace image-based command
prompts

with

text

and

symbol

labels;

expand

the

board

signiﬁcantly;

add

new

input

types.
4. Develop an Arcade Cabinet: Construct a physical arcade cabinet as a
stretch

goal,

unifying

the

project

into

a

single

presentable

unit.

Early Semester: Ideation and Code Refactoring The early weeks of the semester were spent revisiting and cleaning the
Capstone

I

codebase,

which

had

been

developed

rapidly

without

consideration

future

Scripts

were

refactored

to

The

system

between

multiple

distinct

underwater environments. Sketches were produced for creature animations,
the

grid-based

boss

and

the

end-game

scoring

Milestone 2: Game Systems Completed By mid-semester, the core game systems were fully implemented. The boss

The

Multiple

were

fully

An

ofﬁcial

PRESSURIZED,

A

Key Decisions and Pivots One signiﬁcant pivot occurred when the original plan for a fully enclosed,
seated

While

The

arcade

and

more

and

viewable

to

crowd.

This

Another pivot involved command prompt design. Early prototypes used

to

User

The

ﬁnal

A ﬁnal, last-minute change occurred in the board’s backlighting. Update

Rather

Input

LED

to

Arduino

reworked
