PRIMARY TOOL • SECONDARY TOOL • CONTEXT / THEME

Overview

Control Deck is an interactive game experience that blends physical hardware inputs with a digital Unity-based cockpit game. The project centers around a custom-built “control deck” filled with switches, buttons, dials, and sliders. Players receive rapid-fire commands inside a stylized submarine environment and must locate and activate the correct physical input in time to progress.

Project Goal

This project explores how tactile interfaces can heighten immersion, challenge the player, and enhance the narrative of operating a complex machine. By combining physical input systems, custom hardware, and digital game environments, this work demonstrates how interactive media can unify engineering, game design, art, and experiential storytelling. This prototype serves as a foundation for a future large-scale installation or arcade-style experience, reinforcing the value of physical interaction in digital gameplay.
